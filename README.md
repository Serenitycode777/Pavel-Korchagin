# Платформа «Целостность»

Простая страница практик. Вход по коду доступа, без логина и пароля. Код Паша выдаёт вручную после оплаты.

## Файлы
- `content.yaml`: все тексты, порядок практик, ссылки на видео (YouTube id), «когда выполнять», «что даёт» и описание выполнения (открывается в окне «Подробнее о выполнении практики»). Правь слова здесь.
- `files/`: pdf практик от Паши. Кнопка «Сохранить PDF» в окне описания практики отдаёт их (только с кодом).
- `static/style.css`: оформление (цвета в начале файла).
- `app.py`: сервер. `codes.py`: выдача кодов.
- `.env`: секретный ключ (`PLATFORM_SECRET`). В git не попадает. Не теряй его: без него выданные коды перестанут работать.
- `data/platform.sqlite`: коды (только хеши) и статистика входов. В git не попадает.

## Запуск
1. `pip install -r requirements.txt`
2. `python3 codes.py new "Имя"`: создаст `.env` с ключом и выдаст первый код.
3. `python3 app.py`: платформа откроется на `http://127.0.0.1:8090`.
Для боевого запуска нужен домен, https и постоянный запуск (systemd или supervisor) за nginx/caddy. Тогда в `.env`: `COOKIE_SECURE=1`, `TRUST_PROXY=1`.

## Коды
- `python3 codes.py new "Имя человека"`: выдать код на год (365 дней). Показывается один раз, отправь его человеку. Другой срок: `--days 90`, бессрочный: `--days 0`.
- `python3 codes.py extend 5 --days 30`: продлить код №5.
- `python3 codes.py list`: кто получил код, когда входил.
- `python3 codes.py revoke 5`: отозвать код №5 (человек потеряет доступ сразу).
- `python3 codes.py restore 5`: вернуть.
Коды вида `ABEK-M2X9`. Можно вводить без дефиса, строчными, в кириллице.

## Что защищено
Страница практик открывается только с кодом. После 8 неверных попыток с одного адреса вход блокируется на 10 минут. Сессия в браузере живёт 90 дней, отозванный или истёкший код перестаёт работать сразу. Доступ по коду действует год. Видео на YouTube должны быть «по ссылке» (unlisted), тогда их не найдут поиском.
